# Daily Bias v1.0 — 完整 SOP

本模組用 **C1（前天完成日 K）＋C2（昨天完成日 K）** 決定 C3 的方向優先權。盤中最後一根未完成 C3 不參與 Bias 分類；盤後則用最新完成 K 當 C2，建立下一交易日計畫。

## 核心規則

| 情境 | 程式條件（含 buffer） | Bias | 主要目標 |
|---|---|---|---|
| 掃前低後收回 | `C2L < C1L-buffer` 且 `C2C > C1L` | 偏多 | PDH / C2H |
| 掃前高後收回 | `C2H > C1H+buffer` 且 `C2C < C1H` | 偏空 | PDL / C2L |
| 收破前高 | `C2C > C1H+buffer` | 多頭延續 | PDH / C2H |
| 收破前低 | `C2C < C1L-buffer` | 空頭延續 | PDL / C2L |
| 反向收破整根 C1 | C1 與收破方向相反 | 強勢反轉 | 新方向 PDH / PDL |
| 上下雙掃、收回區間 | 同時掃 C1H/C1L、收盤未越界 | 中性 | 等 BOS / CHoCH |
| 沒掃、沒收破 | 收在 C1 區間 | 中性／休息 | 等待 |

`buffer = max(台股 2 個 tick, ATR(C2) × 3%)`。它只用來降低一檔價或極小假刺穿造成的誤判；不是停損距離。

## 操作順序

`Daily Bias → SMC/SNR → Bollinger → 量價動能 → RR → 進場`

1. **Daily Bias**：只決定優先找多、優先防守空方風險，或休息；它不是買賣訊號。
2. **SMC / SNR**：找 SSL/BSL Sweep、CHoCH、BOS、OB、FVG、S1/S2、R1/R2。Bias 與 SMC 同向才提高情境品質。
3. **Bollinger**：偏多時優先要求價格位於中軌之上、中軌斜率向上、%B > 0.5、帶寬擴張；偏空反向處理。
4. **量價動能**：MACD、成交量、OBV、RSI 用來確認延續，不單獨觸發進場。
5. **RR**：近端結構停損與目標不足時一律等待；Daily Bias 失效參考不是交易停損。


## 五層執行分（100 分）

此分數不是勝率，而是「目前多方交易條件完成度」。

| 層級 | 權重 | 內容 |
|---|---:|---|
| Daily Bias | 20 | C1/C2 型態與方向優先權 |
| SMC / SNR | 30 | HH/HL、CHoCH/BOS、Demand、SNR 位置；D1 Sweep 不重複加分 |
| Bollinger | 25 | 中軌位置、MA20 斜率、%B、帶寬擴張、布林型態 |
| 量價動能 | 15 | MACD、20 日量比、OBV、RSI |
| RR / 風險 | 10 | RR 門檻與過度延伸檢查 |

程式的一眼判斷共有 9 個 gate：`Daily Bias / SMC 趨勢 / SNR 位置 / 結構確認 / 流動性 / Demand / Bollinger / 量價動能 / RR`。多方執行分高不代表自動買進；仍必須符合具體「回檔買點」或「突破確認」條件。

## 程式狀態

- **回檔買點（紅）**：Daily Bias 偏多＋有效回測區＋多方結構確認＋RR 合格。
- **突破確認（紅）**：Daily Bias 偏多＋收盤突破＋布林擴張＋量價確認。
- **等待（香檳金）**：Bias 中性、條件不完整、方向衝突、過熱或 RR 不足。
- **結構轉弱（綠）**：偏多劇本遭 Bearish BOS / 主要支撐跌破。
- **流動性誘多／誘空**：Sweep 後沒有延續並出現反向結構。

## 避免重複計分

Daily Bias 與內建 SMC 都來自日 K，因此同一個 D1 Sweep 不應在總分重複加權。本版 Daily Bias 的「條件分」以型態、布林、MA20、MACD、量能做輕量調整；真正盤中確認應使用後續新資料或較低週期結構。
